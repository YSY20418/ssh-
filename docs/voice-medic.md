# 小医灵 · 实现依据与话术工作手册

> 配套文档：语音助手（小鱼儿）的手册见 `docs/voice-corpus.md`。两篇合起来，就是「这个页面上两个智能体分别是怎么做出来的」。
>
> 小医灵是挂在适老预约挂号页上的**医疗预问诊智能体**：一个会漂浮的蓝绿色小光点，点一下变成小机器人，陪老人把症状理清楚、排除危险信号、给出分级建议。**它不诊断、不开药、不处理急症**——这些话术边界由测试逐条把关。

---

## 一、代码用什么写、文件都管什么

和页面其它部分一样：**纯 ES5、零框架、零依赖、无构建**，双击 `index.html` 就能跑。所有文件带 UTF-8 BOM，编码四层防护（HTML 双声明 / 外链 charset / CSS `@charset` / JS BOM）不变。

| 文件 | 管什么 | 谁改 |
| --- | --- | --- |
| `data/medic-kb.json` | **本地医学知识库**：10 类红旗、12 个常见症状主题、兜底话术，全部三语 | **只改这里**（改话术） |
| `scripts/build-medic.mjs` | 质检 + 编译：五条硬规则不过就退出，产出 `medic-kb.js` | 加规则时才改 |
| `public/elder/medic-kb.js` | 编译产物：数据 + 匹配器，挂 `window.XiaoYiLingKB` | **勿手改** |
| `public/elder/medic.js` | 小医灵本体：形态状态机 + 预问诊会话引擎 + 面板 | 改行为时改 |
| `public/elder/medic.css` | 光点 / 机器人 / 气泡 / 面板 / 点选 chips 的样式 | 改样子时改 |
| `scripts/check-medic.mjs` | 沙盒测试：与页面共用同一份 `medic-kb.js` | 加用例时改 |

**为什么知识库也要编译成 JS**：和语料库同一个原因——`file://` 双击打开时，浏览器会把 `fetch` 本地 JSON 当成跨域请求拦掉。所以数据库必须变成 `<script src>` 能加载的 JS，再由 `build-elder-single.mjs` 一起内联进单文件版。

**脚本加载顺序**（有依赖，自检锁）：`icons.js → app.js → speech.js → corpus.js → ai.js → medic-kb.js → medic.js`。小医灵依赖 `app.js` 的 `XiaoYuEr`（三语文案、语言切换、导航白名单）和 `speech.js` 的麦克风授权。

## 二、实现依据：两套状态机叠在一起

### 2.1 形态状态机（管「它长什么样、怎么动」）

```
idle ──鼠标进入──→ hover ──移开──→ idle
  │                  │
  │ 按下             │ 按下
  ▼                  ▼
            （450ms 计时）
          ├─ 计时到且没动 → pressing ──松手──→ 停留 3 秒 ──→ idle
          ├─ 移动 >6px   → dragging ──松手──→ 停留 3 秒 ──→ idle
          └─ 提前松手（点击）→ chat（打开对话面板，暂停漂浮）
                                    │ 关闭面板
                                    ▼
                                  idle（恢复漂浮）
```

关键数字与理由：

| 参数 | 值 | 为什么 |
| --- | --- | --- |
| 漂浮速度 | 20-40 px/s（每段随机） | 够慢，老人看得清、点得到；够快，不像卡住 |
| 随机转向 | 每 1.2-3 秒，角度 ±0.55 rad | 走出自然曲线，不在同一条直线上来回 |
| 长按阈值 | 450 ms | 低于它是「点击」，高于它是「长按」 |
| 拖动阈值 | 6 px | 老人手抖的微小位移不算拖动 |
| 松手停留 | 3 秒 | 让老人看清它停在哪儿，再继续漂 |
| 避让刷新 | 每 500ms | 太频会抖，太疏会漏 |

**避让是硬约束**：光点的轮廓每帧都和一批「不能压」的区域做矩形相交检测——`button / input / textarea / select / .ai__box / .aifab / .ai-inline__btn / .modal__box / #actionbar / .stepbar / #aside / video / .title / .notice__strong / [data-medic-avoid]`。撞上就**一次推到底**（按四个方向的推出距离取最小，且只挑推得出去的方向——贴在视口边缘时往那一边推会被边界钳位抵消，光点会永远卡在原地并把老人的点击挡掉），同时反射速度。初始位置也会先避让再开漂，因为右下角正是「小鱼儿」悬浮按钮待的地方。

### 2.2 预问诊状态机（管「它说什么」）

```
一句话进来
  ├─ 「重新问一次」→ 复位会话
  ├─ 短句含「挂号」→ 走 XiaoYuEr.nav('restart') 回挂号流程
  ├─ 追问中说「就这些」→ 直接给建议
  ├─ ★ 红旗筛查：命中任一红旗 → 立即 120/急诊劝导，会话结束（安全优先）
  ├─ 追问阶段 → 记录回答 → 下一个问题（最多 3 个）
  ├─ 命中症状主题 → 共情 + 红旗提示 + 第 1 个问题
  └─ 都没命中 → 兜底：共情 + 先问「哪里不舒服」
```

**为什么红旗必须放在最前面**：老人说「我头痛得厉害，胸口还疼」，这句话既是症状也是急症信号。顺序反了的话，页面会先陪他聊头痛，急症就被耽误了。所以 `KB.match()` 内部就是「先扫红旗（最长说法赢），再扫主题」——这个顺序写死在匹配器里，不靠调用方记得。

**追问为什么一次只问一个**：规格说「一次最多问 3 个问题」，落到适老界面上，一条消息里塞三个问题老人会慌。所以每条消息只问 **1 个**主问题，配 2-4 个点选 chips；三轮下来正好问完（部位/时间 → 性质/程度 → 背景与伴随），不超过 3 个的上限。

**回答里再出红旗要升级**：问「有没有看东西模糊」，老人点了「看东西模糊」——这是中风信号，必须中断流程升级为急症。所以追问阶段每次回答都会再过一遍红旗筛查。

### 2.3 四级分诊与免责

```
立即急诊（er） / 24 小时内（24h）/ 近期预约门诊（appointment）/ 可先居家观察（home）
```

- 每个主题带一个默认分级；回答里出现过红旗 → 一律升到 `er`。
- 每条建议固定带三句话：**科普**（通俗，说清「原因很多、要医生判断」）、**免责声明**（不能替代医生诊断、开药或处理急症）、**隐私提醒**（判断病情不需要姓名、身份证号和手机号）。
- 来源只写「机构 · 资料名」，**不写死 URL**——防止链接失效，也防止为了凑格式编造出不存在的页面。年份宁可不写，也不能编。

| 素材 | 来源 |
| --- | --- |
| 机器人图形 | 手绘内联 SVG（`medic.js` 里的 `BOT_SVG`）：白主体 + 深青描边 + 淡青小手，和图标体系同一套笔法；眨眼是 `scaleY` 动画，点头是 `rotate` 动画 |

| 医学话术 | 依据公开权威资料的主题化改写：红旗清单来自急症常识与各机构急救科普；分诊与科普参照中华医学会各分会指南、国家卫健委与疾控中心科普、WHO/NHS/默沙东诊疗手册的公开表述 |
| 症状口语说法 | 老人真实会说的样子：客气话、方言口音、同音错字、长短变体（和语料库同一套采集思路） |
| 语音识别 | 复用 `speech.js`（浏览器内 Whisper），不另起一套 |

## 五、智能体怎么做、怎么调教

### 5.1 和「小鱼儿」是什么关系

| | 小鱼儿（`ai.js`） | 小医灵（`medic.js`） |
| --- | --- | --- |
| 管什么 | 替老人操作页面（挂号流程） | 替老人梳理症状（看病前） |
| 动页面吗 | 动，但只走能力清单与导航白名单 | **不动**，只有老人点「我想挂号」才调 `X.nav('restart')` |
| 话术在哪 | `data/corpus.json` | `data/medic-kb.json` |
| 麦克风 | `speech.js` | 同一个 `speech.js`（授权只问一次） |
| 接大模型 | `XiaoYuErAI.setPlanner(fn)` | `XiaoYiLing.setSearch(fn)`（检索增强） |

两者共用 `app.js` 的三语文案表（`registerI18n`）与重绘钩子（`onRender`），所以语言切换时两边一起换。

### 5.2 麦克风为什么只问一次

第一次点麦克风，`speech.js` 的 `ensureMic()` 取一次权限、拿到立刻释放音轨，并把「已授权」记在内存 + `localStorage`。之后：

- 小鱼儿听写 → 先过 `ensureMic()` → 已授权直接录音，**不再弹窗、不再查权限**；
- 小医灵听写 → 复用同一个 `ensureMic()`；
- 被拒绝时**绝不自动重试**（Chrome 被拒后本来也不会再弹），只保留老人手动点的「再试一次」。

### 5.3 检索增强怎么接（RAG 挂点）

页面是纯本地的，没有内置检索工具。规则落地方式：

1. **每次问答先查本地知识库**（`XiaoYiLingKB.match`，等同于本地版 `knowledge_base_search`）；
2. 平台提供检索能力时，用 `XiaoYiLing.setSearch(fn)` 挂上去，`fn(query, lang)` 返回 `Promise<[{org, title, year}]>`，结果按来源优先级合并进引用（最多 3 条）；
3. 检索不到可靠资料 → 明说「我暂未检索到足够可靠的公开资料，建议您直接咨询医生」，**不编造**。

来源优先级（写进知识库规矩，测试逐条校验）：国家卫健委 / 中国疾控中心 / 国家药监局 / 中华医学会指南 → WHO / CDC / NHS / Mayo Clinic / MSD Manual → PubMed 摘要 / Cochrane 系统综述 → 正规医院官网科普。维基百科只作辅助，不单独作为依据。

### 5.4 话术怎么调教：五步加一个主题

1. **看 `data/medic-kb.json` 里现成的主题**，照它的结构写：`patterns`（说法）/ `empathy`（共情）/ `redflagHint`（红旗提示）/ `questions`（追问，最多 3 个，每个带 2-4 个点选项）/ `triage`（分诊）/ `edu`（科普）/ `sources`（1-3 条来源）/ `dept`（建议科室，三语）。
2. **三语都要写**。繁体不是机器转换就行——要按台湾/香港医护用语习惯过一遍。
3. **说法从老人嘴里来**：客气话、方言口音、同音错字、长短变体，各来几条。
4. **跑 `npm run build:medic`**，五条硬规则会拦住：三语不齐 / 追问超 3 个 / 选项不是 2-4 个 / 来源缺机构或资料名、写死 URL、年份不是四位数字 / 同一说法挂两个条目 / **话术里出现诊断、处方、剂量类禁词**。
5. **跑 `npm run check:medic`**：新说法必须逐条命中自己；和红旗词混排必须判红旗；问诊流程一环不能少。

### 5.5 撞车与误伤怎么处理

和语料库同一类问题，两处教训：

- **红旗词和主题词撞车**：「看东西模糊」既是中风信号，也是头痛主题的追问选项——这是**故意的**：老人点这个选项，就该升级为急症。
- **别误伤普通症状**：「发烧两天了」走主题问诊（有 24 小时分诊建议），「高烧三天不退」才升级红旗。阈值卡在「持续 / 不退 / 退烧药压不住」，普通感冒病程不触发。

## 六、本地医学知识库长什么样

```jsonc
{
  "meta": { "langs": ["zh","zh-Hant","en"], "maxQuestions": 3,
            "triageLevels": { "er": {...}, "24h": {...}, "appointment": {...}, "home": {...} },
            "disclaimer": { "zh": "…不能替代医生诊断…" },
            "privacyNote": { "zh": "…不需要姓名、身份证号和手机号…" } },
  "redflags": [ { "id": "chest_pain", "priority": 1,
                  "zh": { "patterns": ["胸痛","胸口疼",…], "reply": "…立即拨打 120…" } } ],
  "topics":   [ { "id": "headache", "priority": 10, "dept": {…},
                  "zh": { "patterns": […], "empathy": "…", "redflagHint": "…",
                          "questions": [{ "q": "…", "options": ["…","…"] }],
                          "triage": "…", "edu": "…",
                          "sources": [{ "org": "中华医学会神经病学分会", "title": "中国偏头痛诊治指南" }] } } ],
  "generic":  { "zh": { "empathy": "…", "questions": […], "triage": "…", "edu": "…", "sources": […] } }
}
```

当前规模：**10 类红旗 + 12 个症状主题 + 1 套兜底，三语共 537 条说法**（红旗 289 / 主题 248）。匹配算法与语料库一致：归一化（小写 + 去标点）→ 先红旗后主题 → 最长说法赢 → 平手看 priority → 语言跟随。

## 七、测试与验收

`npm run check:medic`（19 项断言，与页面共用同一份 `medic-kb.js`）：

| 组 | 验什么 |
| --- | --- |
| A 结构复校 | 规模、三语免责与隐私提醒、四级分诊、主题六字段、来源规矩 |
| B 全量识别 | 537 条说法逐条命中自己的条目 |
| C 红旗优先 | 混排句子一律判红旗；「头痛」alone 不被误伤 |
| D 装饰变体 | 「麻烦问一下…谢谢」包着的症状照样认得出（175 个变体） |
| E 跨语言 | 英文界面说中文、繁体在英文界面，都找得到 |
| F 会话流程 | 共情 → 红旗提示 → 3 问 → 四级分诊 → 科普 → 免责 → 来源；红旗直通 120；回答中升级；兜底；指令复位；一句话回挂号流程；三语问诊 |
| G 禁止事项 | 298 段话术（含引擎实时产出）零诊断 / 零处方 / 零剂量措辞 |
| H 隐私 | 只提醒、不索要 |
| I 速度 | 单条匹配均值约 0.01 ms |
| J 麦克风一次 | `ensureMic` 幂等、`micState` 命中缓存、小医灵不重复要权限 |

真实浏览器端到端（CDP，32 项）：漂浮与速度、悬停气泡、长按变机器人、拖动跟手、松手 3 秒恢复、轻点开面板、问诊全流程点选、红旗 120、**3 秒采样零遮挡**、窄屏无溢出、英文问诊、全程零控制台报错。
